# Флора — кофейня-оранжерея в Самаре

Демо-сайт кофейни «Флора» (Чапаевская ул., 91, Самара). Одностраничный лендинг без сборщика: чистые HTML, CSS и JavaScript.

## Главное

Scroll-driven видео в стиле Apple: прокрутка страницы напрямую управляет кадром ролика. Видео разобрано на 121 WebP-кадр, кадры рисуются на `<canvas>`, а позиция скролла привязана к номеру кадра через GSAP ScrollTrigger с пином секции.

## Стек

- **GSAP 3.15** — ScrollTrigger, ScrollSmoother, SplitText (лежат в `vendor/`)
- **Шрифты** — Cormorant Garamond и Manrope, самохостинг с кириллицей (`assets/fonts/`)
- Никаких зависимостей, сборки и рантайма: достаточно отдать папку статикой

## Запуск

```bash
python -m http.server 8177
```

Затем открыть http://localhost:8177. Открывать `index.html` через `file://` не стоит: кадры и шрифты не загрузятся из-за CORS.

## Структура

```
index.html          разметка всех секций
css/style.css       дизайн-система и адаптив
css/fonts.css       @font-face для самохостинга
js/main.js          анимации, скраббинг видео, меню, модалки
assets/frames/      121 кадр для scroll-анимации
assets/img/         фотографии кофейни и меню
vendor/             GSAP и плагины
```

## Секции

Hero, scroll-видео, о кофейне, галерея атмосферы с лайтбоксом, преимущества, меню с фильтрами и карточками блюд, зелёная пауза, отзывы, карта с маршрутом, финальный экран.

## Доступность и производительность

Учитывается `prefers-reduced-motion` (анимации сворачиваются, секция с видео разворачивается в статичный блок), у интерактивных элементов есть состояния фокуса и aria-атрибуты, изображения грузятся лениво, разметка дополнена Schema.org `CafeOrCoffeeShop`.
